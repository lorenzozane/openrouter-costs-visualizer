Management key and privacy

A management key can create, edit, and delete API keys. Use one with an expiration date. This open-source site sends it directly from your browser to OpenRouter for each sync and never stores it. You can inspect the source code or manage your keys at OpenRouter.

Re-enter the key for each sync. Usage disappears when you clear it, refresh, or close the tab; export a CSV to keep it. Syncs support up to 365 days in smaller parts. Results are daily aggregates, not individual requests.
